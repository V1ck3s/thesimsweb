# Roof port (cRoofLayer, cRoofMeshFactory, roof panel)

Sources: `cRoofLayer.c`, `cRoofMeshFactory.c`, `RoofLayer.s`,
`RoofMeshFactory.s`, `HouseViewer.c`, `Room.c`, `House.c`,
`cWinRoofPanel.c`, `LightLayer.c`.

## Files

- `client/src/game/world/roofs.ts` — cRoofLayer (GenerateRoof,
  DiscoverTilesToRoof, ComputeEaves, ComputeAltitudes, ComputeTypes,
  ComputeStyles), Room::WantsRoof, the cRoofMeshFactory state (pitch,
  pattern), HOUS 0 roof settings reader, cRoofUndoable, the ramp/cap face
  tables, `roofLayersOf(fixed)` (WeakMap side store, version counter).
- `client/src/game/world/roofrender.ts` — RenderRoofPolys (WebGL2 pass on
  the people camera).
- `houseviewer.ts` — calls the roof pass when `drawRoof`; diagonal half
  floors (`drawTileFloor`).
- `rooms.ts` — `computeRooms` ends with `generateRoofs` (end of
  cFixedWorld::ComputeRooms).
- `cutaway.ts` — `setWallState` sets `viewer.drawRoof` (HouseViewer::SetDrawRoof).
- `winlotview.ts` — loads roof settings from the house, wires
  `archRoofHooks` (roof panel → cRoofUndoable on the arch undo manager).
- `housesave.ts` — HOUS 0 writes pitch float + pattern string (version > 0x30).
- `savegame.ts` — XViewer::IssueToolSelection(0) before saving (House::SaveFile).

## Data

cRoofLayer = c2DArray 128x128 of 2-byte cRoofTile, half-tile cells
(row = 2y+j, col = 2x+i). byte0: 0x01 roofed, 0x02 ramp (else cap),
0x04 eave, 0x08 blocked, bits 4-7 style; byte1 altitude. Two layers:
+0x58 (level-1 rooms, drawn above level 1), +0x5c (level 2). GenerateRoof
runs layer 1 first, then layer 0 with `upper` = layer 1. Level-1 tiles under
a level-2 floor, or with stairs (OBJD +0x8a == 3) leading up, are blocked.
Up to 9 rounds of altitudes/types/styles, as the original loop.

Meshes: cRoofMeshFactory builds them in code; the vertex tables were read
by running the PPC routines symbolically (ramp keys 3,4,9,13,else; cap keys
0,8,9,10,14,15,else). Ramp height 1.5·pitch, cap 0.75·pitch. Pitch default
0.6 (clamp 0..2), pattern default `r1_`, fallback `r1_` when the BMP is
missing (`GameData/Roofs/<pattern>.bmp`).

## Rendering assumptions (to check against the original)

- One directional light (-0.3,-1,-0.6) white, viewport ambient 0, white
  material, flat face normals. Roofs are not darkened at night (no hook into
  the lot's time-of-day lighting found for the 3D viewport; unverified).
- NEAREST texture filtering, no back-face culling.
- Depth: same 16-bit z mapping as the people pass (`DEFAULT_DEPTH`).

## Verified

- House01 hip roof at zoom 1/2/3, House02 level-2 roof, rotation.
- Roof panel: steep pitch + r4_ → pitch 1, pattern r4_, undo works.
- HOUS 0 round-trip (version 73, pitch/pattern restored by loadRoofSettings).
- Diagonal half floors (House02 tile 40,26): both halves drawn with their
  room's ambient; light entries filtered by half room (RenderTerrainRow).
- Pool tool active during save: tool deselected first, saved file keeps the
  77 pool tiles.

## Window light

Nothing to port: Room::CollectObjectStats only calls LightLayer::PositionLight
for objects with light source == 1. Windows (light source 0) only feed the
room ambient (already ported in lighting.ts).

## Not ported / gaps

- Animator calls HouseViewer::SetDrawRoof(false) when following a sim (VM side).
- CPState does not re-sync its wall-state button from the viewer on load.
- Roofs are regenerated by computeRooms only; moving stairs alone does not
  regenerate (the original goes through ComputeRooms on object moves too —
  check the placement path).
- House90 (Magic Town): the upper terrace stays unroofed where the game's own
  thumbnail (BMP_ 513) shows it roofed.
- RotateRamp / RotateCap tables are extracted but unused (rotation is done
  on the model matrix).

## Room +0x74 (2026-11-05)

Room::CollectObjectStats sets Room +0x74 (cleared by Room::Clear) when an object of category 8
(object data 59) on the room's tiles, not hidden and counted (object data 29 >= 0), is met:
`(room id & 0x3ff) != 0`. Room::WantsRoof roofs a flat room when +0x74 is set or the room is
not outside. RoomManager::ComputeRooms runs (GlobalDispatch 0xf0) just before GenerateRoof
in cFixedWorld::ComputeRooms, so `roofs.ts` computes the flag from the objects at roof time
(`roomHasCategory8`). In the shipped houses tested, category 8 is the koi pond (outside room
0, so the flag stays 0 there).
