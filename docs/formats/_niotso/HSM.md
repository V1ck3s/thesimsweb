# Niotso wiki snapshot — HSM

> Source: <http://wiki.niotso.org/HSM>  
> Snapshot: 2026-05-01. Cleaned from HTML.

| Type of format | Sound logic |
|---|---|
| Filename extension | `.hsm` |
| First appeared | The Sims 1 |
**HSM** (short for **HIT Symbols**) is a plain-text format that defines constants for opcodes, registers, subroutine addresses, and sound resource IDs for inclusion in the HOT files as well as the MakeTrax source files used to make the HIT files of the game. In The Sims Online, as HOT was replaced by various smaller formats which do not refer to HSM constants, the HSM files are not used ingame in The Sims Online; however, they are still required in The Sims 1.

Its syntax is as follows:

For each constant definition:

***constant*** *Value in decimal* (*Value in hex*)
