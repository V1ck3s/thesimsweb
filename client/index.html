Game files

This server does not provide the game. Import your own copy of The Sims (Complete Collection): select its install folder, the one that holds GameData, ExpansionShared, UserData… The files the game reads (about 3.2 GB) are copied into this browser; nothing is sent to the server.

Help

  • The first start reads the whole object catalog and takes a minute or two; the game files are then kept in this browser and later starts are much faster.
  • Firefox and Chrome (or Edge) are supported. The game is made for a mouse and a keyboard.
  • The game saves as the original does. Export the saves now and then: when they are kept in the browser, clearing this site's data loses them.
  • Offline: once the game has been played on this device, it starts without a network connection, with what it has already loaded (neighborhoods, lots and catalog pages visited). Anything never opened needs the server, and when the saves are kept on the server the game cannot save offline.
  • Install it as an app from the browser's address bar or menu (Chrome, Edge) for a window of its own.
